## Non-Compliant Tags

### Meta – PageView

- **Missing signals:** `ad_storage`, `ad_user_data`, `ad_personalization`
- **Impact:** This tag fires on every page view without consent gating. In the EU, this means cookies and user data are being set before consent is granted, violating GDPR and Consent Mode v2 requirements.
- **Fix:** Add built-in consent: `ad_storage = denied` until user grants consent.

### Meta – Purchase

- **Missing signals:** `ad_storage`, `ad_user_data`, `ad_personalization`
- **Impact:** Purchase conversion events sent to Meta without consent gating. EU purchase data will be silently dropped by Google's consent enforcement, resulting in underreported conversions in Meta Ads Manager.
- **Fix:** Add built-in consent: `ad_storage = denied` until user grants consent.

## Methodology

This report audits the GTM container's tag-level consent configuration against Google's Consent Mode v2 specification. Each tag is classified by vendor category and checked for the required consent signals:

- **Analytics tags** (GA4, Amplitude, etc.) → require `analytics_storage`
- **Advertising tags** (Meta, TikTok, Google Ads, etc.) → require `ad_storage`, `ad_user_data`, `ad_personalization`
- **Functional tags** (chat widgets, CMP, etc.) → require `functionality_storage`

Tags without built-in consent settings will fire regardless of user consent status, potentially violating GDPR and causing permanent data loss under Google's enforcement.
